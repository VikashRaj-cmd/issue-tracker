# MEAN Issue Tracker

A comprehensive Issue Tracker application built with the MEAN stack (MongoDB, Express.js, Angular, Node.js). 

## Project Structure
- `backend/`: Express.js & MongoDB API
- `frontend/`: Angular UI Application
- `screenshots/`: UI previews
- `postman/`: Postman collection for API testing

## Features
- Complete Authentication & Authorization (JWT)
- Projects and Issue Management (Kanban Board)
- Activity Tracking and Logging
- Labeling and User Assignment
- Light/Dark Theme

## Getting Started
Please refer to the individual README files in the `backend/` and `frontend/` folders for detailed setup and deployment instructions.
